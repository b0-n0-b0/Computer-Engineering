# IoT – Load Shedding System

Questo repository raccoglie il materiale relativo al progetto **IoT – Load Shedding System**, sviluppato come parte del percorso magistrale in Computer Engineering presso l'Università di Pisa.

📁 Puoi trovare il progetto completo al seguente link:  
👉 [IoT – Load Shedding System](https://github.com/Tave21/Computer-Engineering-UniPi/tree/main/Master%20Projects/IoT%20-%20Load%20Shedding%20System)

## Descrizione
Il progetto affronta il tema della **gestione intelligente del carico energetico** attraverso tecnologie IoT. L'obiettivo è realizzare un sistema che monitori i consumi e attivi strategie di **load shedding** (riduzione controllata dei carichi) per ottimizzare l’utilizzo delle risorse elettriche, riducendo sprechi e sovraccarichi.

## Contenuti del progetto
- Codice sorgente per microcontrollori e sensori
- Script di comunicazione tra dispositivi
- Documentazione tecnica e relazioni di progetto
- Diagrammi e architettura del sistema

## Requisiti
- Conoscenze di base su IoT e sistemi embedded
- Ambiente di sviluppo compatibile (es. Arduino, ESP32, Raspberry Pi)
- Software di rete (MQTT, HTTP, ecc.)
