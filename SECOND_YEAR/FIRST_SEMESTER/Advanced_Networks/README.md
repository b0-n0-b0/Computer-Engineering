# ANAWS 

Questo repository contiene materiale relativo al corso **ANAWS – Automated Network Configuration**, svolto come parte del corso di laurea magistrale in Computing Engineering presso l'Università di Pisa.

# ANAWS – Automated Network Configuration

📁 Un esempio di progetto è disponibile al seguente link:  
👉 [ANAWS – Automated Network Configuration](https://github.com/Tave21/Computer-Engineering-UniPi/tree/main/Master%20Projects/ANAWS%20-%20Automated%20Network%20Configuration)

## Descrizione
Questo è un progetto che mira a semplificare e automatizzare la configurazione di rete attraverso script, template e strumenti pensati per contesti accademici o di laboratorio. Include esempi pratici, documentazione tecnica e materiali utili per comprendere e replicare l'automazione di setup di rete.

## Contenuto
- Script e configurazioni
- Documentazione e report
- File di esempio per ambienti di rete
